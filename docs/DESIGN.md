# 北宋汴京市井 · 设计文档

## 目标

可玩的北宋汴京市井经营游戏，手机和电脑都能玩，老手机也不卡。先做一幕原型（虹桥汴河），结构留给后续批次拓展。

## 玩法

- 开局500文，7天内赚到5000文即当大掌柜，7天不到即失败
- 每天6行动点：走动不耗点（自由走），进货、卖货、砍价各耗1点
- 8种货：丝绸、茶叶、瓷器、米粮、布匹、酒、果子、香料
- 每天行市刷新：每种货价格在基准价上下浮动，低买高卖
- 砍价：3轮，摊主有耐心条，每轮出价，耐心耗尽即谈崩
- 声望：交易成功涨声望，声望越高砍价越容易、进货价越低
- 夜里结算：房租40文，盈利税5%，然后进入下一天

## 场景

- 第一幕 虹桥汴河（可玩）：汴河、虹桥、石拱桥、码头、商楼、酒楼、茶馆
- 第二幕 御街商铺（待拓展）：等第二批运输资产到了再拼
- 第三幕 瓦舍市集（待拓展）：等第四批市集资产到了再拼

场景全部由`assets/manifest.json`驱动：启动时读表，按记录的位置、旋转、缩放把GLB摆进场景。加新资产只改表，不改代码。

## 技术

- Three.js 0.160.0，本地vendor，不走CDN
- ES模块 + importmap，`GLTFLoader`加载GLB
- 酒楼的GLB是gzip过的（`encoding:"gzip"`），加载时用`DecompressionStream`解压后再交给`GLTFLoader.parse`
- 地面、河水、街道、灯光、雾：程序化生成，资产里没有
- 人物：第三批角色GLB还没到，先用程序化简易人物做摊主占位（圆柱身体加布衣颜色），接口按GLB角色留好，到了直接替换
- 联网：每天全服行市、排行榜、串门摊位走Cloudflare KV，后端挂了自动回落本地种子行市，单机照玩（`src/net.js`，先留接口，第一版用本地种子行市）

## 性能（硬性规则）

- 低端模式默认开：像素比锁1，30帧封顶，无实时阴影（用圆形假阴影）
- 高端机可手动开高清：像素比跟设备，阴影开
- 单场景加载控制在50MB以内；GLB按场景懒加载，离开场景即释放
- 移动端触屏摇杆走路，电脑WASD加方向键

## 模块

- `src/main.js`：启动、渲染循环、帧率控制
- `src/config.js`：常量（从manifest的economy读）
- `src/loader.js`：读manifest、加载GLB（含gzip解压）、失败重试一次
- `src/scene-river.js`：第一幕场景搭建
- `src/player.js`：走动、跟随相机
- `src/npc.js`：摊主（占位人物）、对话
- `src/economy.js`：钱包、库存、行市、砍价、声望、结算
- `src/ui.js`：HUD、面板、对话框
- `src/net.js`：联网接口（先本地种子，后接KV）
